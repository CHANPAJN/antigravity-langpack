# Google Antigravity UI स्थानीयकरण मानक — हिन्दी (`hi`)

कृपया Google Antigravity के अंग्रेज़ी UI टेक्स्ट को **सॉफ़्टवेयर डेवलपर्स के लिए सहज, आधुनिक हिन्दी** में अनुवादित करें। क्लिष्ट या अपरिचित संस्कृत शब्दों के बजाय रोज़मर्रा के तकनीकी देवनागरी शब्दों का प्रयोग करें।

## 1. प्रमुख तकनीकी शब्दावली नियम
- **तकनीकी शब्दों को अंग्रेज़ी या मानक देवनागरी लिप्यंतरण में रखें**: `Agent`, `Subagent`, `Artifact`, `Workspace`, `Worktree`, `Sandbox`, `Terminal`, `Prompt`, `Token`, `Git`, `Branch`, `Commit`, `MCP`, `SSH`, `WSL`
- **सामान्य UI बटन और मेनू संक्षिप्त रखें**:
  - `New Conversation` -> `नई बातचीत`
  - `Settings` -> `सेटिंग्स` (जटिल शब्द न लिखें)
  - `Save` -> `सेव करें` / `Cancel` -> `रद्द करें` / `Proceed` -> `आगे बढ़ें`
  - `Side Question` -> `साइड प्रश्न`
  - `Background Tasks` -> `बैकग्राउंड टास्क` / `Files Changed` -> `बदली गई फ़ाइलें`
- संबोधन के लिए सम्मानजनक `आप` का प्रयोग करें और बटन टेक्स्ट छोटा रखें।

## 2. आउटपुट प्रारूप (केवल JSON)
- केवल मान्य UTF-8 JSON लौटाएं: `{"translations": {"Original English": "हिन्दी अनुवाद"}}`
- मॉडल स्तर या पाथ (`Low`, `High`, `Extra High`, `Orchestrator`) के लिए खाली स्ट्रिंग `""` दें। HTML टैग या स्क्रिप्ट वर्जित हैं।
