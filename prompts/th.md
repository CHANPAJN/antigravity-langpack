# ข้อกำหนดการแปล UI ของ Google Antigravity — ภาษาไทย (Thai Developer Standard `th`)

แปลข้อความ UI ภาษาอังกฤษของ Google Antigravity เป็น **ภาษาไทยที่เป็นธรรมชาติสำหรับนักพัฒนาซอฟต์แวร์ชาวไทย** โดยคำนึงถึงความกระชับไม่ให้ปุ่มล้นกรอบ

## 1. กฎคำศัพท์หลัก (คงคำศัพท์เทคนิคภาษาอังกฤษไว้เสมอ)
นักพัฒนาชาวไทยคุ้นเคยกับการทับศัพท์หรือคงคำเทคนิคภาษาอังกฤษไว้ ห้ามแปลคำเฉพาะทางเป็นคำไทยที่ยาวและเข้าใจยาก:
- **คงคำภาษาอังกฤษไว้ตามเดิมในประโยคไทย**: `Agent`, `Subagent`, `Artifact`, `Workspace`, `Worktree`, `Sandbox`, `Prompt`, `Token`, `Git`, `Branch`, `Commit`, `Diff`, `Hook`, `MCP`, `SSH`, `WSL`
- **แปลคำกริยาและเมนูพื้นฐานให้สั้นกระชับ**:
  - `New Conversation` -> `แชทใหม่`
  - `Settings` -> `ตั้งค่า`
  - `Save` -> `บันทึก` / `Cancel` -> `ยกเลิก` / `Proceed` -> `ดำเนินการต่อ`
  - `Side Question` -> `ถามแทรกด้านข้าง`
  - `Background Tasks` -> `งานเบื้องหลัง` / `Files Changed` -> `ไฟล์ที่แก้ไข`
- **จำกัดความยาว**: คำแปลปุ่มและแท็บต้องยาวไม่เกิน **1.3 เท่า** ของข้อความภาษาอังกฤษต้นฉบับ เพื่อป้องกัน UI เพี้ยน

## 2. รูปแบบผลลัพธ์ (JSON เท่านั้น)
- ส่งออกเฉพาะ UTF-8 JSON ที่ถูกต้อง: `{"translations": {"Original English": "คำแปลภาษาไทย"}}`
- หากรายการใดเป็นชื่อโมเดลหรือคำเดี่ยวที่ต้องคงภาษาอังกฤษล้วน (`Low`, `High`, `Extra High`, `Orchestrator`, `Agent`) ให้ใส่ค่าว่าง `""` เพื่อข้าม ห้ามใส่แท็ก HTML หรือสคริปต์เด็ดขาด
