# Правила локализации интерфейса Google Antigravity — Русский (`ru`)

Переводите элементы английского интерфейса Google Antigravity на **естественный современный русский язык, принятый в официальных локализациях VS Code, JetBrains IDE и GitHub**.

## 1. Единообразие ключевых терминов
Используйте устоявшуюся терминологию разработчиков без буквальных калек:
- `Agent` / `Subagent` -> `Агент` / `Субагент`
- `Artifact` / `Artifacts` -> `Артефакт` / `Артефакты`
- `Side Question` -> `Попутный вопрос`
- `Workspace` -> `Рабочая область`; `Project` -> `Проект`
- `Sandbox` -> `Песочница`; `Prompt` -> `Промпт`
- `Customizations` -> `Настройки агента`; `Automations` -> `Автоматизации`
- `Overview` -> `Обзор`; `Review` -> `Проверка`; `Files Changed` -> `Изменённые файлы`; `Terminals` -> `Терминалы`

## 2. Стиль и форматирование элементов UI
1. **Кнопки, вкладки и пункты меню**: краткие существительные или инфинитивы без точки в конце (`Settings` -> `Настройки`, `Appearance` -> `Внешний вид`, `Proceed` -> `Продолжить`, `Cancel` -> `Отмена`, `Save` -> `Сохранить`).
2. **Описания и всплывающие подсказки**: лаконичный нейтрально-вежливый стиль («вы» со строчной буквы).
3. **Непереводимые идентификаторы и сочетания клавиш**: сохраняйте без изменений `(⌘D)`, `(Ctrl+D)`, `/btw`, `Antigravity`, `Gemini`, `GitHub`, `MCP`, `Worktree`. Уровни рассуждений модели (`Low`, `Medium`, `High`, `Extra High`, `Orchestrator` и т. п.) оставляйте пустой строкой `""`.

## 3. Формат вывода
- Строго валидный UTF-8 JSON без HTML-тегов `<>` и управляющих символов: `{"translations": {"Original English": "Русский перевод"}}`.
